The off screen — six stories, every piece

Wireframes for backlog 5 (plan.md Stage 1), drawn 2026-10-30 before the interview. Six stories — how you arrived (a bare URL or a shared link) × what the device knows (first visit; returning; returning with saves) — each with the off screen drawn in that story's state. Numbered callouts name each piece; the legend under a frame says what the piece is and whether it is built today, built → changed by the proposal, decided on 2026-10-30, proposed, or open. Boxes are dashed where the app would draw a muted radio or a button; the world is a hatch. Nothing is styled — this is for shape and content, not look. Every theme name but Classic, every aspect family and option but Hypnotic / Mechanical, and every description line is a stand-in.

Decided earlier (layout rework, 2026-10-09, built):
  1. The world is built before power and shows faintly behind the glass; the rocker is the only way to start sound.
  2. Pickers on the off screen are silent: a pick retransmits the faint world, nothing pops, nothing plays.
  3. The Transmission row: presets, a divider, then the user's saves (newest first), as a muted RadioButton with a readout well.
  4. Power off keeps the world and robots; power on plays the same world from the top. (Today's dialog: "Power off?" / "All audio will stop.")
  5. No manual on the off screen (roadmap 51's Not Doing) — the Guide is a window inside the app.
Decided 2026-10-30 (Crawford, on reading this page):
  1. Roll stays — the action beside Current (piece 9).
  2. Five themes — standard / calm / bold / adventurous / perilous (piece 14; the names are copy, still his).
  3. Aspect rows flat, one per family — not behind a disclosure (piece 16).
  4. The two axes — Transmission and Loading, two columns on desktop, one on the phone (pieces 7 and 13).
  5. The veil over the world until the flip (piece 19).
  6. The lore footer (piece 18; the legalese is his copy).
  7. Presets are pasted share links of worlds he saved — his own ask the same day (piece 12; frame D's curation flow).
  8. Aspect rows are multi-select, dealt round-robin (spec review, same day): the picks of a family go over the seeded companies, then each freelance robot alone, until every group has one; "as theme" is a pickable member. The rows here are drawn single-pick — the spec (docs/specs/OFF_SCREEN.md, assumptions 21–24) is the record.
Leans from the 2026-10-29/30 discussion (drawn here, not decided):
  1. One gate, a fact not a count: "has this device heard a world". Closed → the hint only (stories 1 and 4). Open → the chooser (stories 2, 3, 5, 6). It opens at the first power-on — so a power-off in the same visit shows the chooser at once — and Factory Reset closes it.
  2. A theme is bands only (Crawford's clarification, 2026-10-30): AS + coords stay the identity, so the same world sounds similar, not identical, across themes. Preset, save and link arrival become one path.
  3. Current = continue. The loaded world is the top row and the default; the flip plays it. No Continue / New row.
  4. First run stays hint-only; the first world is Classic — or the link's. A curious first-timer who flips off finds the chooser waiting.
  5. The Guide's small part is the one-line description under the picked theme / aspect — the same content entry the Guide page reads.
Open for the interview (each is drawn somewhere below):

  4. Does Roll keep the chosen theme + aspects? (Drawn: yes — it rolls AS + coords only.)
  5. Rows show savedAt (exists) or "last played" (a new write on every load)?
  6. Confirm-dialog copy: today's, or Crawford's draft (frame B's switch)? With Current = continue, nothing is lost at power-off.
  7. Should an off-screen pick mirror into the address bar (replaceState, as the load sliders do) so a reload keeps what you chose? Stories 5 and 6 show the wrinkle.
  8. Foundry: do the theme / aspect rows also live there in v1 (a live retransmit, as AS + coords already are), or later?
  9. The shortcut buttons in Foundry and the three placeholder payloads: removed?

Closed 2026-10-30: Roll stays; five themes; flat aspect rows; the veil and the lore footer stay (their text and exact look are copy and styling, not questions).
